Luca Morelli

I am a Ph.D. researcher and Research Assistant at Hamburg University of Technology (TUHH), specializing in secure code engineering and the application of artificial intelligence in software development. My research explores the intersection of software security and AI-driven approaches, with a particular focus on how intelligent systems can support and enhance secure coding practices. As part of my master's thesis, I developed a multi-agent large language model (LLM) framework that simulates the code review process. This system aims to address multiple dimensions of software quality, including security vulnerabilities, overall code correctness, and collaborative review dynamics. By combining security-oriented analysis with AI-driven reasoning, my work seeks to advance the automation and reliability of code reviews in modern development environments. Beyond my dissertation, I am broadly interested in the role of AI in software engineering, including its potential to transform software security practices, improve developer support, and foster more resilient socio-technical systems. My long-term goal is to bridge theoretical advancements with practical applications, ensuring that secure software engineering methods scale effectively to real-world development contexts.

DARTS

DARTS (Detection And Refactoring of Test Smells) is an Intellij plug-in which (1) implements a state-of-the-art detection mechanism to detect instances of three test smell types, i.e., General Fixture, Eager Test, and Lack of Cohesion of Test Methods, at commit-level and (2) enables their automated refactoring through the integrated APIs provided by Intellij.
