Luca Morelli

I am a Ph.D. researcher and Research Assistant at Hamburg University of Technology (TUHH), specializing in secure code engineering and the application of artificial intelligence in software development. My research explores the intersection of software security and AI-driven approaches, with a particular focus on how intelligent systems can support and enhance secure coding practices. As part of my master's thesis, I developed a multi-agent large language model (LLM) framework that simulates the code review process. This system aims to address multiple dimensions of software quality, including security vulnerabilities, overall code correctness, and collaborative review dynamics. By combining security-oriented analysis with AI-driven reasoning, my work seeks to advance the automation and reliability of code reviews in modern development environments.

CRANE - Code Review AI Network Engine

🤖 CRANE is a research-driven system designed to explore the potential of Large Language Models (LLMs) in automating and enhancing the code review process through multi-agent collaboration. At its core, CRANE transforms the traditional code review workflow into a network of LLM agents that engage in structured conversations, each playing a specialized role in reviewing, critiquing, and ultimately resolving code review comments (CRs). This project investigates a novel approach to prompt engineering where LLM agents not only analyze code and comments but also communicate with each other, mimicking a team of human reviewers. Their dialogue is then synthesized into actionable feedback that another LLM agent or a human can use to revise or improve the original code.

Toy3-Compiler

📕 🎓 Toy3 Compiler is a lightweight, educational compiler that translates programs written in the Toy3 language into executable C code. Designed for learning, experimentation, and exploration, Toy3 is a minimal yet expressive language with simple syntax, and this compiler bridges it with real-world execution by generating clean, human-readable C output.
